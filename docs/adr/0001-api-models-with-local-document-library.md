# 模型推理使用 API，个人文档库与检索保留本地

此双 API 决定源于用户现已撤回的 Q5 回答，已由 ADR-0004 替代；以下保留历史取舍，不再作为实施依据。

单用户版本不部署本地生成或 embedding 模型，两种推理职责均调用 API，并分别配置服务地址、模型与凭据；原 PDF、文档库、向量库和关键词检索仍在本机管理，以免要求用户维护本地模型权重和推理环境。用户已确认入库正文可分块发送给 embedding 服务，生成服务接收问题及必要原文证据；这取代最初仅允许生成调用 API、embedding 必须本地的方案，并带来网络、服务配额和调用成本依赖。具体服务和等待时间目标在接入实际 API 后验证，模型变更仍需校验索引兼容性。
