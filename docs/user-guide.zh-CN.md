# 文档库使用说明

[English](user-guide.md) · [接口合同](document-query-api.md)

## 准备与启动

1. 安装 `requirements.txt` 中的完整 Python 依赖，将 `.env.example` 复制为
   `.env`。分别配置本地模型 `LOCAL_EMBEDDING_MODEL`、固定的
   `LOCAL_EMBEDDING_REVISION`、缓存 `LOCAL_EMBEDDING_CACHE_DIR`，以及独立的
   `GENERATION_API_BASE_URL`、`GENERATION_API_KEY`、`GENERATION_MODEL`。
   密钥只放在本机配置，不放在 PDF 或网页中。
2. 首次运行 `python -m scripts.prepare_models --download` 准备公开模型权重和
   tokenizer；之后从缓存本地加载。`python -m scripts.prepare_models` 在不下载的
   情况下检查本地模型。安装、缓存与诊断详见[模型准备说明](model-configuration.md)。
   `auto` 优先可用 GPU；显存不足先降低批大小，必要时回退同模型 CPU，并提示可能变慢。
   没有权重时明确未就绪，不静默改用 hash、其他模型或远程 embedding。
3. 运行 `python -m uvicorn app.main:app --host 127.0.0.1 --port 8766`，打开
   [本地网页](http://127.0.0.1:8766/)。应用存活不等于模型、索引和生成 API 都已就绪。
   本操作使用完整 Python 环境；部署配置另见运行文档，不把轻量容器健康检查当作问答可用。

解析、向量化、原 PDF、SQLite、向量与关键词检索保留本机；首次模型下载不携带文档和问题。
只有问题、理解同范围追问必需的意图材料及必要原文证据发往已配置生成 API，不整份上传 PDF。
CPU/GPU 的实际速度依硬件和模型而异，不承诺未测等待时间。

## 从空库得到引用答案

1. 使用 **上传 PDF** 多选文字 PDF，网页逐份提交，后台可连续排队处理。默认每份
   20 MiB（可配置，界面展示实际限制）；200 页是硬上限。扫描件、混合扫描或不可读内容
   整份失败并显示原因、受影响页码，不把部分可读页当完整入库；本期没有 OCR。空白页不改原页码。
2. 等待 **可提问**，再手动勾选问答文档。首次保持空选择，新 ready 文档不会自动加入。
   刷新只恢复仍有效的已保存 ID；**清空选择** 后刷新仍为空，不能提交问题。
   超过累计 50 份显示设计规模提示，仍可继续上传，不会自动删旧资料。
3. 选择回答语言“跟随问题 / 中文 / English”。显式选项优先于问题中的语言要求；
   中文解释英文条款或英文解释中文条款时，引用摘录仍保留来源语言。
4. **普通问答** 在选定集合内找相关依据，不承诺逐份覆盖，可选超过 5 份。
   **逐文档比较** 对每份分别召回、说明事实或依据不足，最多 5 份，不截取前 5 份冒充完成。
   自动方式会显示本次实际方式，意图不明先澄清；可手动修改选择器覆盖自动判断。
5. 例如上传示例后勾选，问“等待期多久？意外事故有什么例外？”或
   `What is the waiting period and its accident exception?`。默认流式输出。
   点击编号引用打开对应 ID 和原 PDF 页码；同名文件互不覆盖。
   预览按钮、左侧 PDF 下拉框只影响查看器，不改变右侧问题范围。

## 追问与停止

同范围可追问“那意外事故呢？”；每轮重新检索，不从旧助手答案补事实。
改变勾选会新建范围 epoch，即使中间没提问就切回也不恢复旧上下文。
提交时已复制范围、语言和方式；流中改选择不会改变旧请求，迟到结果也不会进入新范围上下文。
**重置** 新建对话而保留文档选择；**停止** 中止本次回答，部分输出明确标为未完成。

## 删除与留存边界

核对具体 ID 和名称后点击 **删除** 并确认。它立即离开选择，相关流式回答中止。
页面展示阶段、未完成原因和 **重试删除**，全部清理前不显示成功。
删除清理应用托管原文件、提取片段、向量、关键词/映射、旧快照和临时副本、历史引用摘录及相关上下文。
旧引用卡显示 **来源已删除**，无摘录、原文件或有效链接。已有答案正文保留，可能包含旧文字/数值，
但不能用于新追问的事实证据。原始输入目录、个人备份和外部 API 的留存不属于本机托管资料清理范围。
成功删除后同内容重传使用新 ID，旧引用不复活；恢复数据库或回退应用时须保留并优先重放删除日志。

一次操作成功不代表第 10 批真实条款、质量、容量和性能验收已完成。
