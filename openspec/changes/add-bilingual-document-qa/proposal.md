# Proposal

## Why

当前系统依赖脚本导入预置 PDF，检索、边界判断和答案展示偏向中文，也缺少用户文档选择、删除和可靠追问。需要在现有轻量 RAG 上建立个人文档库，让用户通过本地多语言向量化与生成模型 API 获得中英文交叉问答，并用公开真实条款验证完整回答的实际可用性。

## What Changes

- 建立单用户文档库：多份文字 PDF 上传、处理状态、原文查看与删除；扫描件或含无法读取扫描内容的混合 PDF 整份拒收，保留明确失败原因。
- embedding 通过本地 Python 模型完成，文档解析、原 PDF、SQLite、Chroma、关键词索引与检索保留本机；生成模型独立配置 API 地址、模型和凭据，仅接收问题、理解追问必需的前文及必要证据。
- 允许首次下载并缓存公开模型权重，后续向量化本地运行；优先 GPU，显存不足先降低批大小，必要时使用同模型 CPU 路径并提示速度变化。失败明确报告，不静默切换 hash、其他模型或远程 embedding。
- 共用网页与 CLI 入库服务，后台处理并一致发布向量和关键词索引；上传完成无需重启即可使用，新文档不会自动改变用户已有查询选择。
- **BREAKING**：问答与批量查询必须提交显式非空文档范围；省略、null、空列表、无效或未就绪 ID 均拒绝，移除旧调用默认全库检索行为，同步更新示例、脚本和测试。
- 普通问答在选定范围内寻找相关证据；明确比较时逐份检索并说明事实或依据不足。自动识别比较意图、显示当前方式并允许手动修改，意图不明先澄清，最多比较 5 份。
- 相同文档范围内支持多轮追问，切换范围重置上下文；前文仅帮助理解本轮问题，每轮重新检索，不把旧答案当成新事实证据。
- 删除会取消相关进行中回答，清除原 PDF、提取正文、向量、关键词索引及历史引用原文摘录；保留答案正文和必要来源标识，标记“来源已删除”，不再供追问使用。
- 支持中问中、中问英、英问中、英问英；回答默认跟随问题语言，可显式指定。原文引用保留来源语言、身份与页码，双语边界与流式/非流式终态一致。
- 统一距离、证据相关性与排序分数，记录 本地 embedding 模型/版本与预处理索引指纹；模型不可用或指纹不匹配时明确降级，不静默切换向量空间。
- 按累计 50 份文档设计与验收，超过提示后可继续上传；单份最多 200 页是硬限制。后台入库、默认流式问答，等待时间目标在本地模型与实际生成 API 联合测试后确定。
- 首批真实验收使用 6 份保险公司官方条款：简体中文、英文各 3 份，覆盖医疗、重疾、寿险，不包含繁体中文文档；合成样本继续承担稳定回归。
- 真实验收包含 40 个可回答问题，四种语言组合各 10 个，每组至少 9 个正确完整且有引用；关键事实/引用错误与范围外证据为零，至少 12 个负例全部正确处理，另验比较、追问、删除场景。
- 首期不含 OCR、多用户账号与权限、整份文档翻译索引、文档原位版本替换、完整界面国际化及 SQL/KG 高级旁路。

## Capabilities

### New Capabilities

- `document-library`：单用户 PDF 身份、上传、质量检查、后台索引发布与恢复、容量提示，以及可恢复的删除和历史来源失效。
- `document-scoped-qa`：强制显式范围、普通问答与逐文档比较、上下文隔离、进行中请求与历史证据归属。
- `bilingual-clause-qa`：本地多语言向量化与生成 API、中英文检索与回答、双语边界、原文引用、真实语料及端到端质量验收。

### Modified Capabilities

无。项目暂无主规格；上述三份 delta 建立相应能力的首份行为合同。

## Impact

- 后端：文档上传/状态/文件/删除端点、ask 与 batch、历史与健康状态、schemas、SQLite 模型及幂等迁移、应用生命周期。
- RAG：共用入库与删除服务、索引协调、显式范围过滤、逐文档比较、追问准备、共享分词、本地 embedding、引用与拒答策略、生成服务。
- 前端：现有双栏布局上增加上传、状态、显式多选、比较方式、回答语言、删除与失效引用；保留 PDF.js 查看器。
- 交付：更新配置示例、两种启动脚本、Docker 与依赖说明；提供本地模型依赖、首次下载/缓存与 CPU/GPU 运行说明，移除中文模型、固定阈值强制覆盖；轻量 Docker 存活不等于完整问答就绪，保留无网络测试替身。
- 验证：真实官方条款采集清单与人工标注、真实本地 embedding 与实际生成 API 联合评测、无网络回归、浏览器与故障恢复验收；具体服务、模型和延迟目标在接入阶段实测记录。
- 决策依据：根目录 `CONTEXT.md` 与已生效的 `docs/adr/0002`、`0003`、`0004`（`0001` 已被 `0004` 取代）。本变更只规划上述行为，全部实施任务保持未完成。
